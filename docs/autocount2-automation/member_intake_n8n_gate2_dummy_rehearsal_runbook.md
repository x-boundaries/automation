# Member Intake n8n Gate 2 Dummy Queue Rehearsal Runbook

Status: Gate 2 operator steps/spec only. This runbook does not add an import-ready n8n workflow export, does not activate a workflow, does not call the bridge, does not run PowerShell, does not touch AC2, and does not authorize AutoCount writes.

## Purpose

Gate 2 proves the hosted/VPS/non-AC2 n8n runtime can move dummy UAT rows through the planned queue and review-state flow before any real queue UAT touches AC2 lookup.

Gate 2 may proceed before the Gate 3 PowerShell lookup preflight because it uses dummy fixture rows only. Gate 3 remains required before Gate 4, where a real n8n queue UAT would touch AC2 lookup through the local Windows bridge.

The n8n-skills plugin is a Codex-side planning and build aid only. The operator must configure and verify the actual hosted/VPS/non-AC2 n8n nodes in the n8n UI. This PR intentionally commits no workflow JSON, no credential bindings, no resource IDs, and no import-ready artifact.

## Gate 2 Boundaries

- Runtime location: hosted/VPS/non-AC2 n8n only.
- Workflow activation: inactive/unpublished.
- Execution mode: manual dummy rehearsal.
- AC2 touch: none.
- Bridge call: none.
- PowerShell: none.
- AC2 credentials: not required.
- AutoCount writes: blocked.
- Public inbound webhook, tunnel, callback, or reverse proxy on the AC2 host: blocked.
- Google Forms / Google Sheets: temporary UAT-only surfaces.
- Bridge contract: source-agnostic for a future custom web form or hosted intake API.

## Manual Inactive n8n Workflow Shape

Create this manually in hosted/VPS/non-AC2 n8n. Keep the workflow inactive/unpublished. Use a Manual Trigger for the first run. If a Schedule Trigger is added for later rehearsal, leave it disabled.

No workflow export is committed by this PR. The exact node parameters, resource selectors, credential binding, and expressions must be verified in the live n8n UI before the operator runs the dummy rehearsal.

1. `Manual Trigger` or disabled `Schedule Trigger` named `Start Gate 2 Dummy Rehearsal`.
2. `Google Sheets` named `Read Dummy UAT Rows Marked For Lookup`.
   - Reads only `Form Responses UAT`.
   - Selects rows with `lookup_requested = yes`.
   - Uses the UAT Google credential selected in the n8n UI.
3. `If` named `Block Already Queued Rows`.
   - Allows only rows where `already_queued` is not `yes`.
4. `If` named `Apply Intake And PDPA Guards`.
   - Allows only dummy rows with `pdpa_status = i_agree`.
   - Blocks `pdpa_status = imported`.
   - Routes blocked rows to review-only status; it never authorizes creation.
5. `Edit Fields` named `Build Allowed Queue Job`.
   - Builds only allowed `Lookup Queue UAT` fields.
   - Keeps `intake_source`, `source_reference`, and `source_row_ref` source-agnostic.
   - Does not add raw member values, normalized member values, names, emails, or phone numbers.
6. `If` named `Validate Encoded Member Value`.
   - Confirms the dummy placeholder cell is present and base64-shaped.
   - Does not log or paste the encoded value literal.
7. `Google Sheets` named `Append Dummy UAT Queue Job`.
   - Appends only `PENDING_LOOKUP` dummy rows to `Lookup Queue UAT`.
8. `Google Sheets` named `Mark Dummy Form Row Queued`.
   - Updates only `already_queued`, `uat_lookup_job_id`, and timestamp/status helper fields.
9. `Google Sheets` named `Read Dummy Bridge Results Ready For n8n`.
   - Reads only `Lookup Results UAT`.
   - This is a dummy result tab; no bridge process writes it during Gate 2.
10. `If` or `Switch` named `Validate Result Schema`.
    - Requires `dry_run_only = true`.
    - Requires `final_write_automation = false`.
    - Allows only the documented review states.
11. `Switch` named `Map Result To Review State`.
    - `member_exists = true` maps to `EXISTING_MEMBER_REVIEW`.
    - `manual_review_required = true` maps to `MANUAL_REVIEW_REQUIRED`.
    - `member_exists = false` and `warning_count = 0` maps to `READY_FOR_CREATE_REVIEW`.
    - Invalid or unexpected shapes map to `LOOKUP_ERROR_REVIEW`.
12. `Google Sheets` named `Update Dummy Form Review Fields`.
    - Updates only approved review/status fields on `Form Responses UAT`.
    - Does not create, update, or delete AutoCount members.
13. `Google Sheets` named `Mark Dummy Result Applied`.
    - Updates only `result_applied_at` on `Lookup Results UAT`.
